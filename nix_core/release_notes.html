Current product/site label: Nix PUCA V5 · September 2026

This page records product and integration behavior. Model checkpoint research, historical runs, and dataset provenance are maintained separately so experiment records are not confused with product releases.

Nix PUCA V5

  • OpenAI-compatible API conversations use isolated, namespaced thread IDs and do not inherit dashboard conversation history.
  • The API rejects structurally recognized OpenWebUI title, tag, and follow-up metadata-generation jobs before they reach Core or a conversation model.
  • Conversation browsing supports search and transcripts for dashboard and API-created chats.
  • Official Luna remains the source-configured default; Casper V5 and Casper V6 beta remain distinct selectable model choices when local artifacts are available.
  • Skills has a catalog install/status interface. The Web Search entry is explicitly not runnable; execution logic remains pending.
